# 🎓 StudyGPT

**Smart Study Companion for Peak Productivity**

StudyGPT is an intelligent Flutter application designed to structure your learning sessions based on your energy levels. By adapting study and break intervals to your fatigue, it helps maintain focus and prevent burnout.

## ✨ Key Features

- **🧠 Adaptive Scheduling**: Input your fatigue level, and the AI algorithm calculates the optimal study-to-break ratio.
- **📊 Insightful Analytics**: Track your "Focus Score", hours studied, and weekly progress with interactive charts.
- **🎯 Module Management**: Organize your revision by subject and track time dedicated to each module.
- **⏱️ Focus Timer**: Integrated timer with visual progress tracking to keep you in the zone.
- **📈 Detailed Reports**: Drill down into your stats to visualize your productivity trends over time.

## 🛠️ Built With

- **[Flutter](https://flutter.dev/)** - UI Toolkit
- **[Provider](https://pub.dev/packages/provider)** - State Management
- **[FL Chart](https://pub.dev/packages/fl_chart)** - Data Visualization
- **[Shared Preferences](https://pub.dev/packages/shared_preferences)** - Local Data Persistence

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/YanisCodes/StudyGPT.git
   ```

2. **Install dependencies**
   ```bash
   flutter pub get
   ```

3. **Run the application**
   ```bash
   flutter run
   ```
