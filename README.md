## ✨ Key Features

| Feature | Description |
|---------|-------------|
| 🧠 **Adaptive Scheduling** | Input your fatigue level — the AI algorithm calculates the optimal study-to-break ratio for you |
| 📊 **Insightful Analytics** | Track your Focus Score, hours studied, and weekly progress with beautiful interactive charts |
| 📂 **Module Management** | Organise your revision by subject and track time dedicated to each module |
| ⏱ **Focus Timer** | Integrated study timer with visual progress tracking to keep you in the zone |
| 📈 **Detailed Reports** | Drill down into your stats to visualise your productivity trends over time |
| 💾 **Offline First** | All data stored locally — no account or internet connection required |
| 🌙 **Fatigue Awareness** | Built specifically to help you study smarter, not harder |

## 🚀 Getting Started

### Prerequisites

- [Flutter SDK](https://flutter.dev/docs/get-started/install) **3.10+**
- [Dart SDK](https://dart.dev/get-dart) **3.10+**

### Install & Run

```bash
# 1. Clone the repository
git clone https://github.com/YanisCodes/StudyGPT.git

# 2. Navigate into the project
cd StudyGPT

# 3. Install dependencies
flutter pub get

# 4. Run the application
flutter run
```

### Build for Release

```bash
# Android APK
flutter build apk --release

# iOS (requires macOS + Xcode)
flutter build ios --release

# Web
flutter build web --release

# Windows
flutter build windows --release

# Linux
flutter build linux --release

# macOS (requires macOS)
flutter build macos --release
```
